Переходимо. Проект Закону про внесення змін до деяких законів України щодо спрощення управління багатоквартирними будинками (реєстраційний номер 7029)(друге читання). Даний проект був прийнятий Верховною Радою України за основу 12 січня 2023 року, надано доручення нашому комітету доопрацювати його до другого читання. Для підготовки законопроекту до другого читання внесено 319 поправок і пропозицій від 50 суб'єктів права законодавчої ініціативи. 
Прошу голову підкомітету Андрія Петровича Стріхарського сповістити рішення підкомітету. Прошу до слова.

СТРІХАРСЬКИЙ А.П. Шановні колеги, на засіданні підкомітету з питань житлової політики та захисту інвестицій в об'єкти будівництва, яке відбулося 25 квітня цього року, розглянуто законопроект за реєстраційним номером 7029 із зауваженнями, пропозиціями суб'єктів права законодавчої ініціативи.
Проект наведено у порівняльній таблиці, яка містить 319 поправок і пропозицій суб'єктів права законодавчої ініціативи, з яких враховано 82 пропозиції, враховано редакційно 16 пропозицій, враховано частково 24 пропозиції, відхилено 197 пропозицій. 
Проектом передбачено зміни до законів України "Про об'єднання співвласників багатоквартирного будинку" та "Про особливості здійснення права власності у багатоквартирному будинку". Змінами пропонується вдосконалити способи повідомлення співвласників про проведення зборів, процедури проведення зборів та голосування на них для прийняття відповідних рішень з утримання і управління багатоквартирним будинком. Визначаються вимоги до протоколу зборів та листків опитування співвласників, встановлюється можливість створення співвласниками листків опитування і їх підписання в електронній формі, удосконалюється порядок передачі співвласникам відповідної документації на будинок.
Також пропонується на період дії воєнного стану в Україні та протягом одного року з дня його припинення чи скасування на місцевості, що входить до переліку територій, на яких ведуться або велися бойові дії, надати правлінню об'єднання або управителю повноваження самостійно приймати рішення про реконструкцію та/або ремонт багатоквартирного будинку, пошкодженого внаслідок бойових дій, за рахунок коштів і майна об'єднання, отриманих для таких цілей як безоплатна (безповоротна) допомога (у тому числі грантова), а також укладати відповідні договори. При цьому вказані повноваження можуть бути достроково припинені за рішенням зборів. 
Набрання чинності законом пропонується через три місяці з дня його опублікування. 
Підкомітетом вирішено запропонувати комітету відхилити наведені у порівняльній таблиці законопроекту 197 пропозицій за номерами: з 2 по 5, з 7 по 10, з 12 по 22, 25, 26, 29, 30, з 32 по 35, 37, 38, 41, 42, 45, 46, з 48 по 51, з 53 по 55, з 59 по 64, з 66 по 71, 73, з 76 по 79, з 84 по 92, з 94 по 97, 104, з 108 по 112, з 119 по 122, з 127 по 130, 133, 135, 138, 139, з 141 по 153, з 157 по 160, з 164 по 170, 174, з 176 по 180, 189, 190, з 192 по 201, з 203 по 206, з 212 по 225, з 228 по 237, 239, 240, з 243 по 246, з 248 по 250, з 252 по 264, 272, 273, 275, 276, 283, 287, 290, з 292 по 295, з 314 по 319.
